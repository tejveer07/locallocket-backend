🛒 LocalLocket – Multi-Vendor Grocery Delivery Platform

LocalLocket is a multi-vendor grocery delivery application designed to connect users with nearby local vendors through a single Android app.
The project focuses on Android app development, clean architecture, and seamless client–server communication using REST APIs.

🚀 Features
👤 User App (Android)

Browse products from multiple vendors

Vendor-wise product listing

Add products to cart

Place and track orders

Secure user authentication

Smooth and responsive UI

🏪 Vendor Support

Vendor-wise product management

Separate product catalogs per vendor

Order handling through backend APIs

🧩 Tech Stack
📱 Android (Client)

Language: Kotlin

UI: Jetpack Compose

Architecture: Modular structure with clear separation of UI and data layers

Networking: REST API integration

🌐 Backend

Framework: Django / FastAPI

APIs: RESTful APIs for users, vendors, products, and orders

Authentication: Token-based authentication

Database: PostgreSQL

🏗️ Architecture Overview

Android app handles UI, user interactions, and API consumption

Backend services manage business logic, authentication, and data persistence

PostgreSQL stores user, vendor, product, and order data

Clean separation between frontend and backend responsibilities

🔄 Core User Flow

User logs into the Android app

App fetches nearby vendors and products via REST APIs

User browses products vendor-wise

Items are added to cart

Order is placed and stored in backend database

Order status is updated and reflected in the app
